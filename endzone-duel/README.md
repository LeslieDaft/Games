# Endzone Duel

Side-view arcade football for two players on one keyboard, or solo against the CPU. First to five touchdowns wins.

Open `index.html` in a modern browser. No build or server is required.

| Action | Player 1 | Player 2 |
| --- | --- | --- |
| Move | A / D | Left / Right |
| Hop | W | Up |
| Steal | S | Down |
| Normal pass | Q | K |
| Jump ball | E | L |
| Pause | Escape | Escape |

Receivers face their quarterbacks and hold position until a pass is thrown. Jump balls trigger a timed leap and use the normal pass curvature aimed at jump-apex catching height. Passes have horizontal and vertical accuracy variation. Jump into passes to intercept; steal at close range. Incomplete passes turn possession over. Includes spiral animation, predictive CPU defense, optional sound, and touch controls for Player 1.

The optional Google Fonts stylesheet uses the internet; system fonts provide a fallback.
